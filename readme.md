# Bayesian Shear Measurement

## General Description
In order to generate digital twins of stage-IV cosmic shear surveys we will first need to know the intrinsic properties of the galaxy sample we ought to simulate as well as those of the instrument through which they are observed. We will learn these features by fitting them simultaneously when measuring the cosmic shear from the survey's images using a hierarchical model. 

Measuring the cosmic shears of individual sources in the images produced by cosmological surveys is a hard task due to the presence of intrinsic ellipticities (IE) and the survey's unique point spread function (PSF). Recently, \citet{lenshmc} proposed a hierarchical approach to problem whereby the multitude of galaxy images are used to constrain the PSF and IE properties of the galaxy sample alongside the individual shear of the each image. The biggest hurdle posed by this new hierarchical approach is the large number of galaxies whose shears need to be simultaneously inferred. In order to overcome this issue, \citet{lenshmc} pioneered the use of gradient-based samplers applied to shear estimator. 

We will develop a new hierarchical Bayesian shear measurement code, \texttt{StatCal}. The PSF modelling in \citet{lenshmc} was limited to an additional pixel level noise contribution. In \texttt{StatCal} we will use the shear measurement code \texttt{MetaCal} \cite{metacal} to estimate the shears of galaxies subject to a hierarchical PSF model at detector frame level. Like in \citet{lenshmc}, we will use Hamiltonian Monte Carlo sampling to simultaneously constrain the PSF parameters alongside with the images' shears. We will use star PSF calibration as an informative prior on the PSF parameters, using galaxies to explore undersampled parts of the detector frame. Leveraging auto-differentiation and GPUs, \texttt{StatCal} will bring down the cost of inferring the shear of each square degree in the survey. Following \citet{lenshmc}, processing 4000 galaxies takes order $\sim1$ second in parallel in a single GPU. Given the galaxy density of Euclid and the number of exposures per image, this translates into $\sim 10$ minutes to process each square degree. 

Armed with a fully hierarchical description of the intrinsic and PSF properties of a galaxy sample, we will use \texttt{LensHMC} to process the Euclid DR2 images to constrain the posterior distribution of the properties of the Euclid galaxy sample as a function of detector frame coordinates. We will then sample the obtained posterior to include these effects in the GS simulations. We will do so by implementing \texttt{LensHMC} forward model as a GLASS module. This GLASS module will allow the user to simultaneously sample intrinsic properties alongside the shear of each galaxy in the GS simulations. In doing so, We will promote the GS simulations to digital twins of the Euclid data.

## Implementation
We will use Galsim to generate fake galaxy images. We will then use the MetaCal implementation in background.py to measure their shears. This implementation doesn't have a solid PSF implementation. We want to model the PSF in terms of the detector frame coordinates at which a galaxy was observed. We can write a fake PSF model where we concolve the GalSim images with an underlying true PSF model, in terms of some Zernike modes depending on wether they fall in one of the four cells of the detector frame. We can then use of order 200 noisy images to infer both their shears and the amplitude of the Zernike modes in each cell of the detector frame. We want to write the statistical model in JAX, using HMC to do the inference.
